🚀 GET STARTED IN 5 MINUTES
═══════════════════════════════════════════════════════════════════════════════

Step 1: Open terminal in backend/
    cd payslip-portal/backend

Step 2: Create virtual environment
    python -m venv venv
    source venv/bin/activate      (macOS/Linux)
    venv\Scripts\activate         (Windows)

Step 3: Install dependencies
    pip install -r requirements.txt

Step 4: Initialize database
    python init_db.py

Step 5: Start backend
    python app.py
    ✅ Running at http://localhost:5000

Step 6: Open another terminal in frontend/
    cd payslip-portal/frontend
    python -m http.server 8000
    ✅ Running at http://localhost:8000

Step 7: Test it!
    - Go to http://localhost:8000
    - Search: Employee ID = EMP001, Month = March, Year = 2026
    - Click "Search Payslip"
    - ✅ Payslip displays!

🔌 API ENDPOINTS (4 Total)
═══════════════════════════════════════════════════════════════════════════════

1. POST /upload-pdf
   Upload payslip PDF and extract data

2. GET /search-payslip
   Search payslip by employee ID, month, year
   Example: /search-payslip?employee_id=EMP001&month=March&year=2026

3. POST /generate-payslip-pdf
   Generate and download payslip as PDF

4. GET /health
   Check API status

All endpoints documented in: API_DOCUMENTATION.md

📞 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Issue: "Port 5000 already in use"
Fix:   Kill process or use different port
       See QUICKSTART.md for details

Issue: "Module not found" error
Fix:   Activate virtual environment first
       python -m venv venv
       source venv/bin/activate

Issue: "No payslip found"
Fix:   Use sample data: EMP001, March 2026
       Check DATABASE.
       Run python init_db.py

Issue: "PDF library not installed"
Fix:   pip install PyMuPDF reportlab
